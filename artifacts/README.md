# Shared artifacts

Non-plugin assets that ship or get shared alongside the plugins — standalone HTML tools,
templates, exports, reference docs.

Anything here is **public**. Personal or client-specific artifacts belong in
`Desktop/Claude/Artifacts/`, not this folder.

Assets a specific plugin depends on do **not** live here — they go inside that plugin's
own skill folder (e.g. `content-repurposer/skills/content-reverse-engineer/assets/`) so
they travel with an install.
